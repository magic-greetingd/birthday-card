تخصيص الهدية ✎

هذه الأداة تظهر لك أنت فقط. بعد التصدير يحصل المستلم على ملف مستقل بلا أدوات تعديل.

بيانات الهدية ✍

اكتب الأسماء والرسالة وسترى التغيير مباشرة في الهدية. لا تكتب معلومات سرّية أو حساسة، فالنص يُحفظ داخل الرابط نفسه.

الصور

استبدل الصور الافتراضية بصورك أو أضف المزيد. تُعالج الصور داخل متصفحك فقط ولا تُرفع إلى أي خادم.

الموسيقى 🎵

استخدم موسيقى تملك حق استخدامها. يُضمَّن الملف داخل ملف الهدية (حتى 7 ميغابايت).

إنشاء الهدية 🔗

يُنشئ رابطًا خاصًا بهذه الهدية فقط يحمل الأسماء والرسالة والألوان. الصور المرفوعة والموسيقى المرفوعة لا تنتقل عبر الرابط؛ لها زر التصدير أدناه.

معاينة وتصدير 🎁

كيف أشارك الهدية مع المستلم؟
  1. للأسماء والرسالة فقط: استخدم «إنشاء الهدية» وأرسل الرابط (يعمل حين يكون الموقع نفسه مستضافًا على رابط https).
  2. للصور والموسيقى المرفوعة: اضغط «تصدير الهدية» ليُنزَّل الملف birthday-gift.html (فيه الصور والموسيقى).
  3. ضعه في مجلد جديد وسمّه index.html، ثم ارفع المجلد إلى خدمة استضافة ثابتة مثل Cloudflare Pages أو Netlify Drop أو GitHub Pages.
  4. انسخ الرابط الذي تعطيه الخدمة وأرسله للمستلم. الرابط وحده لا يحمل الصور، بل الملف المستضاف هو الذي يحملها.
